# Personal Telegram Universal Video Downloader

بوت Telegram شخصي للمالك فقط.

يستقبل روابط الفيديو، يحلل الـ formats المتاحة، ويختار أعلى جودة ممكنة ضمن حد Telegram الآمن، مع ضغط تلقائي عند الحاجة.

## المميزات

- اختيار أعلى جودة ممكنة تحت 48 MB.
- تحليل الـ formats قبل بدء التحميل لتقليل التحميلات غير الضرورية.
- ضغط تكيفي للفيديوهات التي لا توجد لها جودة مناسبة للحجم.
- استهداف حجم يقارب 47 MB عند الضغط، مع هامش أمان لحد Telegram.
- دعم روابط الفيديو المباشرة مثل MP4 وWebM كـ fallback.
- تحسين التعامل مع Facebook وInstagram وTikTok باستخدام yt-dlp وCookies عند الحاجة.
- دعم Browser Impersonation عبر `curl-cffi` لتحسين توافق الاستخراج مع بعض المواقع.
- دعم روابط المشاركة والروابط المختصرة بشكل أفضل.
- تنظيف معاملات التتبع مثل `utm_*` و`fbclid` و`igsh` لتقليل تكرار نفس الرابط.
- منع إعادة إرسال الفيديو الذي تم تحميله سابقًا بدون تأكيد.
- عند العثور على فيديو مكرر يظهر:
  - 🔄 تحميل مرة أخرى
  - ❌ إلغاء
- اختيار جروب الإرسال من `/setgroup` أو `/admin`.
- حفظ جروب الإرسال المختار واستعادته بعد إعادة تشغيل GitHub Runner.
- البوت يعمل للمالك المحدد في `ADMIN_USER_ID` فقط.
- fallback من `send_video` إلى `send_document`.
- تنظيف الملفات المؤقتة بعد انتهاء المهمة.

## GitHub Secrets المطلوبة

### `BOT_TOKEN`

Token البوت من BotFather.

### `ADMIN_USER_ID`

Telegram numeric user ID الخاص بمالك البوت.

### `COOKIES_B64`

اختياري لكنه مهم للمواقع أو الفيديوهات التي تتطلب تسجيل الدخول.

يتم تحويل ملف `cookies.txt` إلى Base64 ووضع الناتج في GitHub Secret بهذا الاسم.

الـ Workflow ينشئ `cookies.txt` أثناء التشغيل ويحذفه بعد انتهاء الـ Runner.

لا تضع:

- BOT_TOKEN
- ADMIN_USER_ID
- COOKIES_B64
- cookies.txt

داخل Git أو داخل الكود.

## اختيار جروب الإرسال

1. أضف البوت إلى الجروب المطلوب.
2. من داخل الجروب استخدم `/setgroup` لتعيينه كجروب الإرسال الحالي.
3. يمكن أيضًا استخدام `/admin` لعرض الجروبات المسجلة واختيار الجروب المطلوب.
4. يتم حفظ الاختيار حتى تغيّره يدويًا.
5. عند اختيار جروب جديد يصبح هو الجروب المستهدف للفيديوهات التالية.

## التعامل مع الفيديو المكرر

إذا تم تحميل نفس الفيديو من قبل، لا يتم رفض الرابط مباشرة.

يظهر تنبيه:

> ⚠️ هذا الفيديو تم تحميله وإرساله من قبل.

ثم يظهر خياران:

- 🔄 تحميل مرة أخرى
- ❌ إلغاء

اختيار "تحميل مرة أخرى" يعيد عملية التحميل والإرسال بشكل طبيعي.

## الحد والحجم

حد Telegram المستخدم في المشروع هو:

- الحد الأقصى الآمن: 48 MB
- حجم الضغط المستهدف: حوالي 47 MB

إذا كانت هناك جودة متاحة بالفعل تحت 48 MB، يتم اختيار أعلى جودة ممكنة بدون ضغط غير ضروري.

إذا لم توجد جودة مناسبة، يتم استخدام FFmpeg لتقليل الحجم تلقائيًا.

## المواقع ودعم Cookies

يعتمد الاستخراج الأساسي على `yt-dlp`.

المواقع التي تحتاج جلسة تسجيل دخول أو محتوى مقيد قد تحتاج `COOKIES_B64` صالحًا.

وجود Cookies في GitHub Secret لا يعني بالضرورة أن الجلسة ما زالت صالحة؛ يجب أن تكون Cookies حديثة وصالحة للحساب والموقع.

## GitHub Actions

يعمل البوت على GitHub Actions.

الـ workflow:

- يثبت Python والاعتماديات.
- يثبت FFmpeg.
- يجهز yt-dlp وJavaScript runtime عند الحاجة.
- يجهز Cookies اختياريًا.
- يشغل البوت.
- يحافظ على حالة اختيار الجروب عبر المستودع.
- يستخدم `concurrency` لمنع تشغيل أكثر من نسخة في نفس الوقت.

## Dependencies

المشروع يستخدم:

- Python 3.11
- python-telegram-bot
- yt-dlp
- curl-cffi
- FFmpeg
- yt-dlp EJS support
- Deno عند الحاجة لاستخراج بعض المواقع

## ملاحظات

نجاح تحميل أي فيديو يعتمد على إمكانية وصول الخادم إلى المحتوى وعلى دعم `yt-dlp` للموقع وعلى صلاحية Cookies عند الحاجة.

المحتوى الخاص أو المقيد أو المحمي بتسجيل الدخول قد يتطلب جلسة Cookies صالحة.
